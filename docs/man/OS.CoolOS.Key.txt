Nonblocking CoolOS input queries borrow mutable OS.Terminal.Input.
keyPending returns Result[Bool, IoError]. keyPop returns Result[Option[Key],
IoError]: None means no queued key, Some holds a typed OS.Terminal.Key.
The caller retains Input and must release it. For blocking/timed reads use
Man("OS.Terminal"). Unsupported host operations return Other.
Example: C:/Warm/Examples/kernel/Key.warm.
