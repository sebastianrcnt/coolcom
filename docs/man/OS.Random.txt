Deterministic, noncryptographic xorshift64. No capability required.
seeded(seed) constructs a Free Rng; a zero seed selects a fixed nonzero state.
next(&!rng) updates its state and returns Nat64. Identical seeds produce the
same sequence; copying this Free value also copies its generator state.
This API supplies no cryptographic entropy or security randomness.
